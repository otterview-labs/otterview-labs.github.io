agentBridge：在手机上继续代码任务

查看和回复 Codex、Claude Code 会话。

Otterview Labs2026.09.26

本文内容

查看任务，再继续处理连接自己的运行环境反馈问题GitHub

agentBridge 用于在 Android 手机上查看和回复 Codex、Claude Code 的代码任务。任务仍在连接的电脑或服务器上运行，手机提供继续处理的入口。

查看任务，再继续处理

进入会话后查看任务进度和终端输出，再回复当前任务。对于等待确认的操作，按会话里的提示处理。

连接自己的运行环境

使用前需要部署项目并配置机器连接。安装步骤、支持的功能和版本变化，请查看仓库 README。

反馈问题

遇到问题可以在仓库提交 Issue，说明运行环境和复现步骤。日志中请去除密钥和业务数据。
