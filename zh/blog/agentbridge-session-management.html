agentBridge：统一管理 CLI 会话

本地与远程代码助手会话的集中查看。

Otterview Labs2026.09.26

本文内容

会话与任务信息本地与远程访问GitHub

同时使用 Codex、Claude Code 和 Gemini CLI 时，任务信息往往分散在终端窗口和 SSH 会话中。agentBridge 将本地与远程会话集中在一个界面，便于查看任务状态和继续处理任务。

会话与任务信息

除了终端输出，处理一个任务还需要确认所在仓库、分支、使用的模型，以及等待确认的操作。集中查看这些信息，可以减少在不同终端之间切换。

本地与远程访问

会话在所连接的机器上运行。agentBridge 提供查看和管理入口，使用者仍需配置相应机器的连接与权限。

项目代码和安装说明见 agentBridge 仓库。功能与配置以当前版本的 README 为准。
