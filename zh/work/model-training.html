Lutrio 模型训练平台

面向第一次训练模型的使用者。用自然语言告诉 Agent 你要做什么，在引导下准备数据、提交训练并查看结果。素材、标注、数据版本和模型产物都保留在项目中，关键操作由你确认。

海外测试环境目前提供受邀登录。完整数据与训练执行服务尚未开放；下方为产品流程与演示界面，实际评估范围需先与团队确认。

先和 Agent 说说需求

告诉 Agent 你想训练什么模型、现在有哪些素材。助手可以准备操作参数、查询任务；你确认后再执行。训练过程仍保留数据审核、任务状态和评测记录，方便逐步检查。

先建一个项目

选择目标检测或图文问答，接入项目素材。图片可以直接导入，视频文件和实时流可以抽帧采集；已有数据也可以继续使用。

把标注看清楚

目标检测在标注台查看图片、修改框和类别；图文问答查看画面、问题和模型判断，再逐条修正或确认。AI 标注先作为候选结果，人工审核后再发布。

用确定的数据训练

审核好的样本发布为数据版本。选择版本和基座模型，设置训练参数，再提交任务。检测项目训练检测模型，图文项目进行视觉语言模型微调。

查看这次训练的结果

在项目中查看训练状态、模型产物和评测记录。对比基座与微调模型的回答，检查具体样本，再决定是否继续调整数据或训练参数。

补充训练素材

缺少样本时，可通过参考图和提示词生成新图片。Agent 帮你准备生图参数，提交前确认；生成结果继续进入标注与审核流程。
