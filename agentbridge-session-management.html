把多个 CLI 会话放到同一处

当 Codex、Claude Code 和 Gemini CLI 同时出现在工作流里，真正麻烦的往往不是启动它们，而是记住它们各自跑到了哪里。

我们把 agentBridge 做成一个很小的会话入口：本机的会话和远程机器上的会话，都可以从同一个界面查看。

会话本身就是上下文

一个编程任务很少只发生在一个终端里。仓库、分支、模型、最近一次输出和正在等待的命令，拼在一起才是完整的上下文。

如果这些信息散落在窗口、终端标签和远程连接里，切换本身就会变成工作。agentBridge 先把这些上下文放回一个列表里，让人能快速回到正确的位置。

本机优先，远程可见

默认情况下，会话仍然在自己的机器上运行。远程查看是为了减少切换，不是为了把代码和凭据搬到第三方服务中。

这也决定了项目的取舍：先把启动、查看和恢复做顺，再逐步补上搜索、标签和更细的状态管理。
