Local deployment for our open-source projects

Deployment choices for agentBridge and SightIndex.

Otterview Labs2026.09.26

On this page

Data and accessProject documentationGitHub

agentBridge and SightIndex are self-hosted projects. Services run on the user’s computer or server, with installation and configuration documented in each repository.

Data and access

The projects handle different data: coding sessions in agentBridge, image and video indexes in SightIndex. Before deploying, review data directories, access permissions and any external model service configuration.

Self-hosting provides control over data and services. It also requires the operator to manage updates, backups and troubleshooting.

Project documentation

Read the repository README for installation and runtime configuration. When reporting a deployment issue, include the environment, reproduction steps and relevant logs. Remove credentials and business data before sharing logs.
