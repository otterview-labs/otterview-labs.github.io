SightIndex: local image and video search

Build an index, search your media and inspect the source files.

SightIndex provides local image and video search. Once material has been indexed, queries can return relevant results with access to the original image or video content.

Indexes and source files

An index stores information needed for retrieval. Source files remain in the user’s storage environment. Index maintenance needs to account for source updates, deletions and rebuilds.

Returning to the source

Results should correspond to source material so users can confirm what was found. File locations and access permissions are part of deployment configuration.

See the SightIndex repository for installation, supported features and configuration examples.
