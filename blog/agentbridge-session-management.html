agentBridge: continue coding tasks on your phone

View and reply to Codex and Claude Code sessions.

agentBridge lets you view and reply to Codex and Claude Code tasks on Android. Tasks keep running on the connected computer or server; the phone provides a way to continue working with them.

Check a task and continue

Open a session to review progress and terminal output, then reply to the task. Follow the session prompts for operations waiting for approval.

Connect your environment

Deploy the project and configure machine connections before use. See the repository README for setup, supported features and version changes.

Report a problem

Open a repository issue with your environment and reproduction steps. Remove credentials and business data from any logs.
