agentBridge: managing CLI sessions

A shared interface for local and remote coding sessions.

Otterview Labs2026.09.26

On this page

Session and task contextLocal and remote accessGitHub

When using Codex, Claude Code and Gemini CLI together, task information can be spread across terminal windows and SSH sessions. agentBridge brings local and remote sessions into one interface for viewing progress and resuming work.

Session and task context

Terminal output is only part of the information needed to handle a task. The repository, branch, model and pending approvals also matter. Viewing them together reduces switching between terminals.

Local and remote access

Sessions run on the connected machine. agentBridge provides a viewing and management interface; the operator configures machine connections and permissions.

Source code and installation instructions are available in the agentBridge repository. Refer to the current README for supported features and configuration.
