About

Visual search for the field, with hardware built to stay there.

Otterview Labs is a technical line within JetLinks, developed by the Chongqing Haijing Intelligent team.

We are following two tracks. The first is visual search: find people, vehicles and events in camera footage, then have a person verify the result. The second is edge hardware: run search and inference on a small box in a factory, campus or showroom, keeping data on site and the device running for the long term.

Software comes first as public repositories. Hardware is still at the prototype stage; robots are a later plan.

Repos

  • agentBridgeusableTypeScript · Apache-2.0

    A console for AI coding sessions. Sessions live in tmux on your machine and state lives in SQLite. There's a web UI, a CLI, an Android app and a Feishu bot.

  • SightIndexexperimentalPython · FastAPI · Vue

    Self-hosted visual search. Postgres or SQLite for metadata. Milvus and the ReID service are optional.

  • LutraPipedemoC# · .NET 10 · GStreamer

    The edge box's video pipeline. It counts every decoded frame on every stream and skips the preview JPEG when nothing in the picture moves.

  • ChatBIprototypeFastAPI · Vue

    Ask a business database questions in plain Chinese. Handles several data sources and can send reports on a schedule.

Each repo's licence file is the one that counts. SightIndex's face and person matching handle biometric data. Get consent, access control and a retention limit sorted before you deploy them.

Hardware

One device is actually being built: the edge vision box. A few cameras plug in, decoding and inference happen on the box, and results stay on the local network. It runs on a Qualcomm Q900.

We have also built a robot arm and a fire control host. A kiosk with a screen and a mic, vision and voice modules for device makers, and an inspection recorder come later.

The arm is already in the field; a more complete robot form can come later.
