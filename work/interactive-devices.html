Tourism badges & desktop assistant

Two interactive devices: tourism IP badges and a programmer desktop assistant.

Tourism IP badge

A wearable round-screen badge with character voice guides and digital destination stamps for tourism and museum settings.

Programmer desktop assistant

Displays coding assistant task status, provides approval reminders and allows device-based approval or rejection. Models run on the computer; the device handles display and interaction.
