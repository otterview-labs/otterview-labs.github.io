Model training platform

A workspace for people new to model training. Tell the Agent what you want to do in natural language, then follow the workflow to prepare data, submit training and inspect results. Media, labels, dataset versions and model artifacts stay in the project, and you confirm operations before execution.

  1. 01Talk to the Agent
  2. 02Prepare and review data
  3. 03Confirm training operations
  4. 04Check training jobs
  5. 05Inspect model results

Start with the Agent

Tell the Agent what you want to train and what material you have. It can prepare operation parameters and query jobs, with execution after your confirmation. Data review, job status and evaluation records remain available throughout the workflow.

Start with a project

Choose object detection or visual Q&A, then add your source material. Import images or sample frames from video files and live streams. Existing data can also be reused.

Review the labels

For detection, inspect images and edit boxes and classes. For visual Q&A, check the scene, questions and model judgments, then correct or confirm each item. AI labels remain proposals until human review.

Train on a known version

Publish reviewed samples as a dataset version. Choose the version and base model, set training parameters and submit a job. Detection projects train detection models; visual Q&A projects fine-tune vision-language models.

Inspect the results

View job status, model artifacts and evaluation records within the project. Compare base and fine-tuned responses on specific samples before deciding whether to adjust the data or training parameters.

Add training samples

Use a reference image and prompt to generate additional images when you need more samples. The Agent prepares generation parameters for confirmation; generated images then go through labeling and review.
